# Qualification music fixture

`music-carefree-30s.wav` is a 30-second excerpt of [Carefree by Kevin MacLeod](https://incompetech.com/music/royalty-free/mp3-royaltyfree/Carefree.mp3), provided under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The source MP3 was trimmed and converted to 48 kHz stereo signed 16-bit PCM with FFmpeg 9.0.1. This is not the original master. See `qualification_inputs.json` for source and derived checksums. The speech recording is not redistributed here.
